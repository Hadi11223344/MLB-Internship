# Day 6 – Model Evaluation, Cross-Validation & Hyperparameter Tuning

## Overview
Explored model evaluation, cross-validation, learning curves, and hyperparameter optimization using the Breast Cancer Wisconsin dataset.

## Topics Covered
- Training vs Testing Performance
- Underfitting and Overfitting
- Cross-Validation
- Stratified K-Fold
- Learning Curves
- Model Evaluation Metrics
- Hyperparameters and Regularization
- GridSearchCV
- Model Selection and Generalization

## Projects
### Breast Cancer Classification
Built a Logistic Regression classification pipeline using:
- StandardScaler
- Logistic Regression
- Stratified 5-Fold Cross-Validation
- GridSearchCV

### Hyperparameter Optimization
Optimized the Logistic Regression regularization parameter `C` using GridSearchCV, evaluating multiple metrics and selecting the configuration based on cross-validated malignant recall.

### Evaluation
Evaluated the baseline and tuned models using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Cross-Validation

## Tools
Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
